# 后端权限验证

本次使用真实 Express 路由、JWT 验证、鉴权服务和 HTTP 请求验证以下边界；数据库由隔离 fixture 替代，不连接线上账号或数据。

| 场景 | 后端预期结果 |
| --- | --- |
| 未登录、无效 JWT、大屏凭据访问学校管理 | 401 |
| 普通教师、外校 ADMIN 读取/修改学校资料及管理列表 | 403，数据不变 |
| 本校 ADMIN/OWNER 读取学校资料，本校 ADMIN 修改资料 | 正常成功，不返回密码哈希 |
| ADMIN 授予 OWNER、降级/删除现有 OWNER | 403，成员不变 |
| 最后 OWNER 自行降级/删除 | 409；添加接任 OWNER 后可降级 |
| ADMIN 通过创建管理员或批量教师导入覆盖 OWNER | 403，凭据不变 |
| 学校 VIEWER 读取自己的学校上下文 | 正常成功，无共享密码哈希 |
| 大屏请求外班作业目标或伪造名单所属班级 | 越权发布 403；名单仍从绑定班级读取 |
| 只读班主任读取相关走班空间的他人草稿 | 显式目标/详情拒绝；不指定目标的列表也不返回 |
| 有写权限的教师读取草稿 | 正常成功 |
| 学校关闭 OAuth 后的历史 OAuth 教师 | 列表不返回从目标空间派生的无权内容；与详情一致保留作者自身分支 |
| 大屏查看/恢复通知历史，或恢复作业中的通知快照 | 409，发布记录不变 |
| 初始化密钥未配置时使用空密钥签名的初始化令牌 | 503，拒绝接受 |
