# NPClassworksKV v1.3.0 · Yamada（山田凉）

## 版本概述

**v1.3.0，代号 Yamada（山田凉）**，是基于 v1.2.5 的 NPEP 自习服务更新，配套 **NPClassworks v1.3.0** 与 **NPEduTools v1.1.0 · EVA-02（二号机）**。

KV 负责学校与班级身份、口令和权限、有效规则、请求与回执，以及自习报告、座位表和私有照片。实际麦克风采样、USB 参考读取、照片捕获和全屏展示由桌面端执行；保存服务端配置不等于设备已应用或正在采集。

## 新增功能

### 模式独立的学校自习规则

- 按学期、年级和班级设置继承、覆盖或关闭，支持星期、生效／结束日期、学校日历例外与跨午夜边界；日常、考试模式分别设置时间段，允许其中一种或两种模式都不定时监测。
- 新配置默认 **Asia/Shanghai，19:00–21:30**，保留用户明确自定义安排，不将某所学校的开始日期写成全体部署规则。有效排程与展示、作业、双阈值及照片策略一并投递，并记录配置版本。
- 支持提前 **5 分钟**的定时展示与座位表准备，但采集授权仍从实际开始边界生效；准备提示在开始前 **2 分钟**持续 **10 秒**。学校日常时间来自 ClassIsland，考试模式使用 Windows 时间，状态和报告携带时间来源。
- 检查设备协议能力、班级归属、模式及回执新鲜度。模式切换、旧执行代际或过期观测不能继续证明本次规则已经执行。
- 支持手动自习报告与学校定时接管的归属，保留已结束手动报告，不把手动会话伪装为学校定时会话。

### 班级管理口令、接入与设备策略

- 新增学校班级管理口令与修订，支持管理员批准设备申请并设置口令，以及预授权班级后使用学校服务地址与口令接入；保留旧配对兼容路径。
- 班级开放 NPEP 前核验口令已配置。预授权允许提前设置自习规则，设备未连接时仍明确缺少执行确认，不把预授权当成配对或采集完成。
- 学校管理口令通过验证材料存储，不作为明文设备列表返回；接入、口令变更和执行会话继续检查学校范围、部署身份与修订。
- 接收设备麦克风／摄像头清单，投递默认设备及锁定策略；本机经管理验证解锁后保持解锁，直到学校再次锁定。拒绝旧设备代际上报，避免陈旧列表覆盖当前状态。

### 作业来源与自习座位表

- 自习配置可指定作业来源行政班，复用学期、年级、授课规则和适用走班来源解析，输出今日作业并去重。轮换默认 **60 秒**，由学校配置，具体分页与阅读衔接交给原生展示端。
- 保存并下发 **自习座位表**图片与修订；学校和已绑定大屏都可更新，大屏只限本班、无需另输口令。按预期版本处理并发修改，冲突不静默覆盖，记录设备上传来源。
- 座位表和照片是不同资源：座位表用于自习查看及准备阶段，不参与作业轮换，也不自动开放私有照片访问。

### 会话报告、校准来源与联合详情

- 接收带固定学校／学期／班级归属的统计，按会话去重，拒绝同一标识的不同内容、无效时间、异常统计及陈旧上报；保留平均值、峰值、覆盖率、削波、趋势与双阈值／提醒统计。
- 区分 **dBFS** 与 **估算 dB(A)**，保存原始数字电平、参考来源及有效性。DLY-2202 USB 参考保留 **Beta** 来源；服务端校验报告，不把 USB 收到一帧或校准写入成功当成声学精度验收。
- 报告按不可变会话归属查询，与照片、退出验证及异常恢复事件组成同页详情。旧报告缺少可靠归属时继续从设备历史查看，不自动归入设备后来绑定的班级。
- 状态、显示回执、操作受理和报告分别存储；刷新后仍区分正在执行、未知、已结束及上传结果，避免旧成功回执冒充本次采集。

### 私有照片、退出与异常恢复事件

- 默认关闭照片策略，启用后高阈值连续超限默认 **3 秒**，照片最小间隔默认 **30 秒**，与定时退出意图、异常恢复触发共用限频；“注意纪律”的默认 **10 分钟**提醒间隔独立处理。
- 接收单张 JPEG，限制最长边 **1280 像素**、单张 **256 KiB**，校验实际图片、摘要、上传许可、时段、会话及策略；不接收原始音频或视频片段。
- 照片默认保留 **30 天**、最长 **180 天**，延长保留需确认风险；捕获后补传仍受许可、归属与到期检查约束，不能靠重试续期。
- 图片放在学校服务端的私有存储，通过鉴权读取，不提供公开静态链接。仅同校 **OWNER 与第二管理员**可查看，照片过期后不可继续访问；维护任务处理到期数据及未完成上传。
- 保存定时退出意图、验证失败和异常中断／恢复事件，关联实际照片状态；事件存在不等于照片已经捕获或上传。服务端保留期限与离线设备缓存、数据库及文件备份副本的期限分别处理。

## Bug 修复与可靠性

- 修复未来时间／陈旧观测、统计校验、USB 参考来源及报告时钟变化边界，避免无效观测进入正常报告。
- 修复考试请求合并去重、重新绑定后的报告归属和旧代际设备策略上报；重试不跨班沿用旧许可。
- 修复学校口令前置错误合约、配对夹具及新增外键表的备份恢复验证，完整迁移升级路径纳入真实 PostgreSQL 验收。
- 服务页、健康检查与诊断统一显示 **1.3.0 / Yamada（山田凉）**。既有部署身份、恢复代际和部署代理接口保留，本版不要求改造 NPEssentials。

## 数据库迁移与升级

### 相对于 v1.2.5 新增的六项迁移

| 迁移 | 作用 |
| --- | --- |
| `20261009010000_npep_study_settings` | 学校自习策略、作用范围与配置修订 |
| `20261010000000_npep_seating` | 自习座位表、版本及更新记录 |
| `20261010010000_npep_study_device_receipts` | 原生自习展示／执行回执 |
| `20261011020000_npep_study_photos` | 私有照片元数据、上传许可与保留期限 |
| `20261011030000_npep_study_exit_events` | 退出验证与恢复事件 |
| `20261011040000_npep_school_management` | 班级学校管理口令与设备清单／策略 |
| `20261012000000_npep_legacy_study_schedule` | 将仅配置旧噪音排程的范围自动迁入学校自习设置 |

使用仓库的 **完整 Prisma 迁移链**，不手工挑选 SQL，也不以修改生成客户端代替迁移。

部署启动时自动执行上述兼容迁移，随后才启动 KV。迁移逐项保留旧排程的自定义星期、开始／结束时间、年级继承、班级覆盖或关闭；不将旧的 19:15 等已保存时段替换为 19:00。已有新自习设置不覆盖，已继承新年级策略的班级也不再套用旧班级覆盖。没有旧排程的范围不会被自动启用。

旧周排程没有生效日期，兼容起点取旧配置保存日与迁移前一日的较早者（北京时间），以衔接跨午夜时段；不硬编码学校的开学日期，不推测节假日或补课安排。迁移仅创建日常模式时段，考试模式仍为空，摄像头拍照默认关闭。旧排程原数据保留，每个迁移范围记录系统审计；数据库迁移只应用一次，重复执行也不会改写已有策略。

### 升级顺序与保留内容

1. 备份 PostgreSQL、当前应用版本与配置、NPEP 外部身份目录，并纳入私有图片存储。数据库转储不包含身份文件或独立图片文件，需分别备份。
2. 先更新 KV、执行 `prisma migrate deploy` 并核对 `/ready`，再更新网页 v1.3.0，最后更新 NPEduTools v1.1.0。旧桌面在线不等于支持新自习、设备与照片协议。
3. 已激活服务保留原部署身份、设备登记和配对，不重复首次初始化；保留明确自定义排程，不把新默认时间批量覆盖到既有学校安排。
4. 配置或补齐班级管理口令，核对预授权范围、两种模式的时段、日历、时间来源及设备回执。没有安排的模式保持不执行，不推测学校实际取值。
5. 启用照片前核对私有存储权限、清理任务、查看人员和保留风险；旧照片、退出记录、报告及备份可能有不同保留边界，部署方应明确说明，不承诺全部备份随在线数据同时删除。
6. 回退代码不等于回退数据库。保留新增表、身份及备份后的写入；确需恢复时遵守部署代际与旧授权处理流程，不清空身份目录或直接用旧身份覆盖当前实例。

## 测试与已知限制

- 已合并 PR [#8](https://github.com/tempChanghong/NPClassworksKV/pull/8) 的必要 CI 通过，包含当前三仓契约、真实 PostgreSQL、迁移升级和恢复检查。
- 本轮隔离原生 PostgreSQL 的真实 HTTP／KV／.NET／恢复测试 **47 项通过、0 跳过**，迁移升级检查通过；网页配对全栈与 **183 项**浏览器回归通过。未使用生产数据库进行探索验证。
- 自动化不替代 DLY-2202、目标一体机、现场麦克风／摄像头、学校时间与长期运行验收，USB 联机校准继续标为 **Beta**。
- 服务器修改或撤销不能立即通知离线设备；照片捕获、进程恢复与实际采样恢复分别核实。数据不用于班级噪音排名，不接收原音频，不向星火动力云端转传照片。
- Release 草稿和已合并源码不代表所有服务器已部署、迁移或完成生产验收。
