# NPClassworksKV v1.3.5 · Yamada（山田凉）

当前源码版本为 **v1.3.5**，代号保持 **Yamada（山田凉）**。NPClassworks 与 NPClassworksKV 源码版本一致，配套 **NPEduTools v1.1.5 · EVA-02（二号机）**。本轮为本地版本与维护检查，不代表发布、部署或生产验收。

## 当前范围

- 保留 NPEP 学校／班级预授权、身份配对、有效规则计算、设备回执和报告／照片／自习座位表存储。
- 部署时的既有迁移链可将只配置过旧噪音安排、尚未建立新自习安排的配置迁入新策略；已配置的新安排和用户自定义规则保留。
- 新安排默认 19:15–21:30；估算 dB(A) 双阈值默认 50／65，与原始 dBFS 分开。版本提升不批量覆写已有配置。
- 服务首页、健康信息和诊断从 package.json 读取版本与代号。

## 验证边界

本轮只使用本地构建、自动测试及隔离接口夹具。不连接生产学校，不执行数据库迁移，不使用 Docker，不修改 NPEssentials。真实数据库、学校设备、USB、摄像头与部署验收仍须分别核对；历史发布说明保留。
