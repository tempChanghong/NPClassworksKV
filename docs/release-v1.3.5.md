# NPClassworksKV v1.3.5 · Yamada（山田凉）

v1.3.5 配合统一的学校自习管理入口，完善旧排程迁移和新配置默认值。代号保持 **Yamada（山田凉）**，配套 **NPClassworks v1.3.5** 与 **NPEduTools v1.1.5 · EVA-02（二号机）**。

## 服务行为与改进

- **旧安排自动衔接**：部署启动前的兼容迁移，将“旧噪音排程已设置、新自习策略尚未设置”的范围迁入日常模式自习策略。保留年级继承、班级覆盖／关闭、自定义星期与时段；已有新策略不覆盖，没有旧安排的范围不自动启用。
- **新默认值**：学校新安排默认 **Asia/Shanghai、19:15–21:30**；估算声压级新策略双阈值默认 **50／65**，与原始 dBFS 阈值分开。版本升级不批量重写已保存的安排和阈值。
- 继续提供班级预授权、口令与身份配对、有效规则计算、设备策略／回执、今日作业来源、自习座位表、统计报告与私有照片存储。服务器保存配置不代表设备已应用或正在采集。
- 首页、健康信息和诊断统一读取 **1.3.5 / Yamada（山田凉）** 服务元数据，保持既有部署身份与前后端兼容性检查。

## 数据库迁移与升级

相对于 v1.3.0 的关键兼容迁移是 `20261012000000_npep_legacy_study_schedule`。使用仓库完整 Prisma 迁移链，不挑选单个 SQL，也不以重生成客户端替代迁移。

迁移仅创建需要衔接的日常模式设置，保留原始旧配置和审计记录；不推测节假日、补课日或某所学校的启用日期，不自行创建考试模式时段、开启摄像头或替换自定义规则。迁移已应用的部署不会重复覆盖配置。

1. 备份 PostgreSQL、学校配置、NPEP 身份目录及独立私有图片存储。数据库转储不包含外部身份和图片文件。
2. 先升级 KV、执行 `prisma migrate deploy` 并核对 `/ready`，再升级网页 v1.3.5 和 NPEduTools v1.1.5。已激活部署保留原身份、设备登记及绑定。
3. 核对旧安排迁入情况、模式与日期／星期、管理口令、默认设备及执行回执。离线设备不能仅凭服务端配置确认已收到更新。
4. 回退代码不等于回退数据库；保留身份与新增写入，按部署恢复规则处理，不直接清空身份或覆盖恢复代际。

## 数据与验证边界

报告按会话归属、去重和统计单位保存；照片、退出记录及座位表继续遵守学校范围和修订检查。照片默认保留 **30 天**、最长 **180 天**，仅授权的学校管理人员查看；在线清理不承诺同步删除所有备份副本。

质量检查、真实隔离 PostgreSQL、迁移／恢复与精确三仓组合 CI 通过。未以生产数据库探索、真实 USB 或声学测试替代隔离验证；联机参考保持 Beta。dBFS 不是实际声压级，估算 dB(A) 也不是计量级校准，不用于班级排名。服务不接收原音频或摄像头视频，不向星火动力云端转传学校照片。

本 Release 提供服务源码及发布说明，不附带数据库、私有配置、密钥或身份文件；发布状态与具体学校部署／现场验收分开核对。本版不要求改造 NPEssentials。
