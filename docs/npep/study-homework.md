# 自习当天作业只读协议（0.12）

学校后台沿用已实现的 homework 设置：OwnClass 或 SelectedClasses，rotationSeconds 默认 60、范围 15–600。设备不自行选择来源，也不调用浏览器凭据接口。

POST /api/v2/npep/device/study-settings/homework 使用设备凭据、X-NPEP-Version: 0.12 和关联 requestId。请求包含 context、version、date、snapshotId、index，可选 purpose 仅允许 Manual；首次 index=0/snapshotId=null。后续请求携带初次返回的内容 SHA-256，并在所有块中保留 purpose。有效设备、当前运行会话、当前配置版本和 15 秒内的 APPLIED 配置回执必须全部匹配。

省略 purpose 时保留原有定时自习限制：准备/自习阶段、有效学校时钟和日期均须匹配。手动自习准备或运行时由 Host 加上 purpose=Manual，日期使用 Windows 本机日期，KV 独立核对北京时间当天日期并要求学校已启用作业展示；不要求正在定时时段，也不要求 ClassIsland 时钟在线。仍使用当前绑定学校的有效作业来源，不接受本机指定班级，不授予采集、排程或照片权限。没有手动任务且不在学校自习阶段时不新增后台轮询。新版桌面的手动作业读取需要 KV 同时支持此可选字段；旧 KV 的严格校验会拒绝该请求，不能通过伪造学校定时状态回退。

服务端复用 studySettingsRepository.homeworkSources 和现有大屏走班授课规则。查询仅 ASSIGNMENT/PUBLISHED、boardDate 等于学校日期、publishAt 不晚于服务端实际时间、目标空间位于所选来源。定时自习日期以 offset-free 学校墙上时间为准，手动自习则按上面的 Windows/北京时间核对；UTC 仅用作数据库 DATE 的载体。发布可见性仍由服务端时间决定。科目无发布内容不生成卡片，一条 publication 多目标命中只生成一项，保留所有命中的来源名称。仅返回 ID、revision、科目、标题、正文、来源 ID/名称；不返回人员、凭据、音视频。

每次读取重新授权并读取完整可见快照，publication 读锁后再次查询正文。后续块快照变化返回 HOMEWORK_CHANGED，客户端丢弃不完整内容；不拼接两个版本。完整 UTF-8 JSON 最多 2 MiB、500 条发布，每块最多 16 KiB/base64，最多 128 块。超过限制返回错误，不截断为成功。此传输块不是展示分页。本次手动作业读取改动无需新增数据库模型或迁移。

Host 独立任务每 30 秒读取，单次整体截止 30 秒。配置心跳与采集执行保留原任务；作业失败不撤销有效采集许可。缓存仅内存保存，通常在 60 秒后过期；已授权的定时自习进入失联续采时，网络、临时服务不可用和限频故障保留本时段已下载的当天作业，其他错误仍撤下缓存。绑定、配置版本、日期或作业开关变化时清除。定时自习还依赖有效阶段和学校时钟；手动自习在离开准备/运行阶段后清除，不因 ClassIsland 时钟缺失而停止取数。旧 0.10/0.11 服务不支持时只显示作业尚未支持，不回退浏览器、不影响采集许可。0.10/0.11 严格远程消息定义不扩展字段。

本机 study.status 和 manual.study.status 只携带轻量 Homework 元信息；study.homework 返回独立块，带快照和块序号；不夹带噪音趋势，符合 64 KiB Named Pipe 帧限。App 校验块次序、数量、完整哈希、日期、版本、字段和重复项，再交给 WPF。手动会话版本与学校作业配置版本分别校验：普通正文更新等待阅读周期结束，学校配置版本变化则立即撤下旧页面。配置变化期间取消旧请求，旧结果不得恢复到页面。

WPF 按字体实测文字高度，短作业最多六格，中等篇幅使用三列通高卡片并保留整科内容，长作业使用两列并拆续页，保留全部文字及字素边界。每次只测大致一页长度，避免反复排版整篇长正文。来源行过长时省略显示，完整名称保留在提示中。当前页阅读计时使用单调时钟；新版本等待当前页阅读周期结束。只有一页也持续跟踪阅读周期；暂停、临时收起、准备和开始/结束覆盖提示期间不计时，恢复后给完整周期。首次取得内容或当前没有作业时立即显示。日期/配置/授权失效立即撤下，优先于延后更新。

此协议只证明读取与缓存；不把它当作 WPF 可见、真实采集或线上验收回执。当前验证使用真实 Express/NPEP API、合成 ClassIsland/采样、内存数据库替身，以及独立 Named Pipe/WPF 测试。实际 PostgreSQL、校园网络、大屏、真实字体 DPI/内存和设备仍待人工验收。
