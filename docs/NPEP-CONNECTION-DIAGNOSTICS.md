# NPEP 连接诊断

NPEP 路由继续绕过通用访问/错误日志。新增专用记录仅在请求失败、客户端中断或到完成耗时超过两秒时写出；每个路由实例每分钟最多 120 条，多余数量在下一条记录的 `suppressedSinceLast` 中说明。

记录包含 UTC 时间、固定端点类别、规范请求 UUID、HTTP 状态、耗时、结果和白名单错误码。无 URL、查询、学校/设备身份、请求体、授权头、管理口令、数据库异常、照片或音频。日志写出失败不会改变响应。`kind=npep-connection` 可和桌面脱敏历史的请求编号对应；中断不代表服务端事务一定未提交。

此改动没有调整数据库事务、行锁、身份检查、限流、配置或数据迁移。错误处理仍返回原协议结构；照片和座位表子路由也只补脱敏错误码。日志的实际持久性与保留期限由既有运行环境负责，本地隔离测试不代表线上日志已启用。
