# NPEP Pre 20261001：KV 配套更新

本次主分支更新包含考试／日常模式与方案接口、0.6 原生噪音控制和统计、0.7 学校排程政策／设备执行／报告来源。配套 NPClassworks 与 NPEduTools 更新见各仓预览版说明；KV 包版本仍为 `1.1.0`，应按实际完整提交记录定位版本。

## 数据库升级

沿用 Prisma 完整迁移链，本次新增：

| 迁移 | 功能 |
| --- | --- |
| `20260926000000_npep_runtime_control` | 远程模式与操作记录 |
| `20260927000000_npep_exam_plans` | 考试方案 |
| `20260930000000_npep_noise` | 原生噪音统计与命令 |
| `20261001000000_npep_noise_schedules` | 学校政策与修订请求 |
| `20261001010000_npep_noise_schedule_runtime` | 设备排程与来源映射 |

更新前保留数据库备份、配置和现运行镜像；保留既有 NPEP 身份与卷，不重新初始化／激活。新增表不删除旧业务字段。回退应用先保留新表，恢复数据库会丢失备份后的数据，须明确选择。

0.6 报告结构不变，来源由 0.7 会话映射关联；未知来源不能当作手动。配对即授权当前能力，学校规则仅在新版桌面、有效绑定、已保存麦克风及可靠学校时间下执行。离线桌面可使用尚未到期的确认租期，服务器禁用或回退不能立即撤销离线采集。

这是预览版：隔离测试及部分开发电脑联调已完成，真实班级大屏、学校排程现场验收仍未完成。源码合并会触发既有 main 部署流水线；实际部署、迁移与健康状态必须单独核实，不能把本地测试结果当作生产通过。

本地调试使用 Windows 原生 PostgreSQL；见 [本地开发](classworks-2-local-debugging.md)。生产部署继续沿用既有配置与代理，本次不改变部署方式。
